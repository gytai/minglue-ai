# PostgreSQL 数据库驱动 (覆盖 requirements.txt 中的 MySQL 默认驱动)
#
# 用法一: 手动
#   pip install -r requirements.txt
#   pip uninstall -y asyncmy PyMySQL
#   pip install -r requirements-pg.txt
#
# 用法二: 由 start_backend_*.sh 自动处理 (推荐)
#   REQUIREMENTS_FILE=requirements-pg.txt ./start_backend_dev.sh
#   REQUIREMENTS_FILE=requirements-pg.txt ./start_backend_prod.sh
#
# 本文件通过 -r 继承 requirements.txt 的所有基础依赖, 仅追加 PG 驱动。
# psycopg2 需要系统存在 libpq (APScheduler job store 走同步驱动)。

-r requirements.txt
asyncpg==0.30.0
psycopg2==2.9.10
